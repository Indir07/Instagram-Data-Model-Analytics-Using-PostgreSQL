# Instagram-Data-Model-Analytics-Using-PostgreSQL

## 🚀 **Project Overview**

The goal of this project is to design a relational database model for Instagram and perform analytics on user interactions. Key features include:
- **Data Modeling**: Created tables with foreign key relationships to reflect real-world user interactions.
- **Structured Querying**: Wrote complex SQL queries to filter, aggregate, and analyze data.
- **Advanced SQL Techniques**: Used **CTEs**, **window functions**, and **date manipulation** to generate insights.
- **Real-World Application**: Simulated scenarios like user engagement, post popularity, and follower analytics.
